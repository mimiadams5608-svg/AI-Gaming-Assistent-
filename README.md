# AI Game Finder

**Live Website:** https://aga-eta-six.vercel.app/

## Project Overview

AI Game Finder is a website that recommends games based on users' interests and preferences. It aims to help gamers discover new games, including indie games.

## Intended Audience

The website is designed for gamers who want to discover games that match their interests, as well as players looking for games from smaller or independent developers.

## Features

- Select game genres, moods, and playstyles.
- Get game recommendations based on your preferences.
- See why each game matches your interests.
- Create an account and log in.
- Save favorite games and manage them through your profile.

## How It Works

Users select their preferences, and the website matches them with games using its game data source and recommendation logic. Users can review the recommended games and their match explanations. Signed-in users can also save their favorite games.

## Technologies

- HTML
- CSS
- JavaScript
- Supabase for authentication and user-related data
- External game database/API for game information
- Vercel for deployment

## Future Improvements
