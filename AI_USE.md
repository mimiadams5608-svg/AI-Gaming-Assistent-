# AI Game Finder — AI Use Note

## AI Tool Used
ChatGPT

## How I Used AI
I used ChatGPT as a development assistant while building AI Game Finder. It helped me understand and work with HTML, CSS, and JavaScript; troubleshoot issues; improve the website's features; and organize project documentation.

I also used AI to help plan the game recommendation process, connect the website to game data, and improve the account and favorite-game features.

## My Contributions
I made decisions about the website's purpose, design, and functionality. I worked on the code, followed troubleshooting steps, made changes to the project, and tested features on the live website.

## Meaningful Improvement
One important improvement was connecting AI Game Finder to an external game database/API. This expanded the game's discovery possibilities beyond a small, manually entered collection.

## What I Tested
I manually tested the live website for:
- Generating game recommendations with normal input.
- Handling empty preferences.
- Updating recommendations after changing preferences.
- Navigating controls with a keyboard.
- Using the website at a narrow screen width.

All five tests passed based on my observed results.

## Verification
I checked the website's behavior by using the live application and verifying the results of the tests above. AI-assisted suggestions were reviewed through implementation and testing.

## Limitations
AI-generated suggestions may contain errors and require human review. Game availability and information depend on the data source used by the website.
